#  Device tree of Realme GT3/Neo5

It was announced & released on February 2023

## Device specifications

Basic   | Spec Sheet
-------:|:-------------------------
SoC     | Qualcomm Snapdragon 8+ Gen 1 (SM8475)
CPU     | Octa-core (1x3.0 GHz Cortex-X2 & 3x2.5 GHz Cortex-A710 & 4x1.80 GHz Cortex-A510)
GPU     | Adreno 730
Memory  | 12GB/16GB RAM
Shipped Android Version | 13.0 with RealmeUI 4
Storage | 256GB/512/1024GB UFS 3.1
Battery | 5000 mAh/150w OR 4600 mAh/240w Charging
Display | AMOLED, 6.74 inches, 1240 x 2772 pixels
Extra   | Illuminated 4 channel RGB (on the back)

## What doesn't work
- Camera stabilisation
- Screen anti flicker
- MMAP audio (disabled)
